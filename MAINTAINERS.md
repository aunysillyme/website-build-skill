# Maintainers

Owner: the public repository account at [website-build-skill](https://github.com/aunysillyme/website-build-skill).
Path ownership: [.github/CODEOWNERS](https://github.com/aunysillyme/website-build-skill/blob/main/.github/CODEOWNERS).

- Scope: canonical method, adapters, generated bundles, content checks and release review.
- Contributors: reproduce defects, preserve source attribution and supply sanitized evidence.
- Decisions: maintainers approve scope, licensing, compatibility claims and authorized releases.
- Responses: best effort; no paid support, deadline or guaranteed host compatibility.
- Security: use [private reporting](SECURITY.md); conduct reports follow [the covenant](CODE_OF_CONDUCT.md).
- Absence: keep publication blocked when no accountable maintainer can review the exact artifacts.
- Succession: document accepted ownership changes here and in CODEOWNERS before granting release access.
